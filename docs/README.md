# Glitch Studio Build Docs

These docs are meant to be pasted into Cursor or kept in the project root as planning documentation.

Recommended order:

1. Read `01-product-requirements.md`
2. Read `02-technical-architecture.md`
3. Read `03-mvp-build-plan.md`
4. Give Cursor `04-cursor-master-prompt.md`
5. Use `05-acceptance-tests.md` before approving the build
6. Use `06-phase-2-roadmap.md` only after Phase 1 works

Project name: **Glitch Studio**

Core concept: A browser-based creative editor where users upload an image, select exact areas, apply glitch effects only to those selected regions, stack edits as non-destructive layers, and export the final artwork.
