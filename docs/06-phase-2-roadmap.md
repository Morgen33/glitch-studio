# Glitch Studio Phase 2 Roadmap

Do not begin Phase 2 until Phase 1 passes the acceptance tests.

## Phase 2 Goal

Upgrade Glitch Studio from a simple selective glitch MVP into a stronger creative editor with more effects, better mask controls, presets, and stronger layer behavior.

## Phase 2 Features

### More Glitch Effects

Add:

- Scanlines
- Digital noise
- VHS tracking damage
- Broken signal bands
- Chromatic blur
- Posterize corruption
- Holographic noise
- Edge bleed
- Digital decay

### Effect Stacking

Allow a single layer to contain multiple effects.

Requirements:

- Add multiple effects to one layer
- Reorder effects inside a layer
- Toggle individual effects on/off
- Edit each effect settings independently
- Render effects in order

### Presets

Add preset panel with:

- Clean RGB Break
- VHS Ghost Layer
- Cyberpunk Tear
- Digital Decay
- Broken Signal
- Holographic Noise
- Analog Nightmare
- Museum Glitch

Each preset should:

- Create a layer or effect stack
- Use editable settings
- Not flatten the base image

### Better Mask Tools

Add:

- Feather mask
- Invert mask
- Fill mask
- Expand mask
- Contract mask
- Mask opacity preview control

### Better Layer Controls

Add:

- Blend mode dropdown
- Move layer up
- Move layer down
- Lock layer
- Reset layer settings

### Keyboard Shortcuts

Add:

- B for brush
- E for eraser
- Cmd/Ctrl+Z for undo
- Cmd/Ctrl+Shift+Z for redo
- Delete to remove selected layer

## Phase 3 Preview

Phase 3 is where the more advanced dimensional stuff begins:

- 3D depth glitch
- Parallax preview
- Floating fragments
- Fake extrusion
- Z-axis layer separation
- WebGL shader pipeline
- Animated GIF export
- MP4 export
